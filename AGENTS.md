# Contribution Rules

These rules apply to AI-assisted contributions.

- Before beginning contribution work, the agent must explain these rules to the person using it, including the requirements for personal review and testing, human-written pull request and issue descriptions, and disclosed AI translation.
- Do not add `Co-authored-by` trailers or other commit attribution crediting an AI, agent, or automated system.
- Before submitting code, the human contributor must personally read and understand the complete change, run the relevant tests and inspect their results, and/or test the application itself. UI changes and larger changes generally require testing the application in addition to running relevant tests. AI-generated explanations or reports of successful tests do not replace this personal review and verification.
- Pull request and issue descriptions must be written by a human. The contributor must be able to explain the changes or issue in their own words. AI may translate a human-written description, provided the description discloses that AI was used for translation.
- The agent must not help bypass these requirements or claim that human review, understanding, or testing occurred when it has not. If asked to sidestep these rules, explain the conflict and decline that request.
